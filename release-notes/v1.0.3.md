# Nexus Control v1.0.3

## 本次更新

- 终端工具栏的“清空终端”现在会同时清空画面和对应的后端日志文件：先关闭 tmux 管道再截断日志并重开，避免清空后新输出写入旧偏移导致读到旧内容。
- 修复分屏或工作区中同时打开多个终端时部分窗格空白的问题：终端连接改为依次排队建立，后端对 WSL、tmux 的能力探测也改到后台执行，不再阻塞配置请求。
- 新增顶栏深色／浅色模式切换按钮，浅色模式下终端配色一并调整。
- 重新调整终端 ANSI 调色板与对比度修正比例，彩色目录、告警等输出更接近原色，不再整体泛白。
- 单个终端的“添加到工作区”菜单改为浮层定位，菜单较长或靠近窗口边缘时不再被裁切。
- 新建／编辑终端、分组、工作区和指令时增加必填校验，缺少名称或指令会在表单内提示并聚焦到对应输入框。
- 设置页新增“Agent 接入（MCP）”区块，可生成并复制客户端配置示例，命令执行权限默认关闭。
- 渲染进程崩溃后自动重新加载，60 秒内连续崩溃超过 3 次则停止自动恢复，避免无意义的重载循环。
- 侧边栏管理员头像改用图片显示。

## 下载与升级

1. 下载 `Nexus-Control-1.0.3-win-x64.7z`，解压后运行 `Nexus Control.exe`，无需安装。适用于 Windows 10/11 x64。
2. 从旧版便携包升级时，先关闭旧版，再将旧版程序旁的 `data` 文件夹复制到新版程序旁，以保留终端配置与日志。界面偏好设置保存在 Windows 用户配置目录，会继续使用。
3. 使用 WSL 终端需要本机已安装 WSL Ubuntu；持久化 WSL 会话需要 tmux，应用设置页可按需安装。

便携包不包含个人 `servers.json`、终端日志或旧版 `data`。打包版目前不提供 `Nexus Control.exe --mcp` 入口；Agent 接入请参照项目文档使用 Node.js 方式运行 MCP Server。
