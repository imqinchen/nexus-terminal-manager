# Nexus Control v1.0.2

## 本次更新

- 新增终端工作区：可创建空工作区、编辑名称，并把最多 4 个终端放入同一个工作区分屏查看。同一终端可以加入多个工作区。
- 3 个终端时显示横向三屏，可分别拖动两条分割线；4 个终端时显示 2×2 布局，可拖动中间的竖线和横线。双击分割线恢复均分，布局比例会按工作区保存。
- 服务管理中的终端现在可通过“更多操作 → 移至分组”转移到其他服务分组，终端配置和工作区关联会保留。
- 调整终端工作区的焦点、分屏和尺寸处理，修复三屏分割线重叠或无法拖动的问题。

## 下载与升级

1. 下载 `Nexus-Control-1.0.2-win-x64.zip`，解压后运行 `Nexus Control.exe`，无需安装。适用于 Windows 10/11 x64。
2. 从旧版便携包升级时，先关闭旧版，再将旧版程序旁的 `data` 文件夹复制到新版程序旁，以保留终端配置与日志。界面偏好设置保存在 Windows 用户配置目录，会继续使用。
3. 使用 WSL 终端需要本机已安装 WSL Ubuntu；持久化 WSL 会话需要 tmux，应用设置页可按需安装。

便携包不包含个人 `servers.json`、终端日志或旧版 `data`。打包版目前不提供 `Nexus Control.exe --mcp` 入口；Agent 接入请参照项目文档使用 Node.js 方式运行 MCP Server。
